# docs/technical_report/ — companion technical report

**Casimir Cosmology: Derivations and Numerical Validation** — Alan Zhang, report version 1.1 (2026-10-22), 223 pages;
companion technical report of the Letter and the paper, not independently peer reviewed. Version 1.0 (2026-10-17,
198 pages) is the copy in code and data versions 1.0.0 and 1.1.0.

- `main.pdf` — the report as built on 2026-10-22 (pdflatex → bibtex → pdflatex ×2; 0 LaTeX errors, 0 undefined
  references or citations); 58 files in this folder: `main.tex`, 29 chapter files, 21 figure PDFs, `refs.bib`, `main.bbl`,
  `main.pdf`, `numbers.tex`, `numbers_c170.tex`, `dnec_macros.tex`, this README.
- `main.tex`, `chapters/` (one file per section; fixed numbering: Part I Secs. 1–17, Part II Secs. 18–22, Part III
  Sec. 23, Appendices A–B; version 1.1 adds subsections only at the ends of Secs. 7, 9, 18, 19, 20 and 22),
  `figures/`, `dnec_macros.tex`, `refs.bib` — the LaTeX source with the comment lines removed (the same files as the
  source archive of the report's own Zenodo record).
- `main.bbl` — the BibTeX output of `refs.bib`, so that the source also compiles without running BibTeX (as on
  arXiv).
- `numbers.tex` — `numbers/numbers.tex` without its comment lines (the macros are identical; generated from
  `numbers/numbers_v12.json`; the Letter and the paper use the same file).
- `numbers_c170.tex` — the macros of the static-box and abelian-Higgs numbers, the same file as in the Letter's source
  (generated by `prl_supplement/numbers/make_numbers_c170.py`), without its comment lines.

Sec. 22 (reproduction guide) and Appendix B (table of key numbers) contain tables generated from this package
(result-directory READMEs, `VERIFY.json`, `numbers/numbers_v12.json`, `numbers_run05.csv`, the figure table of the
top-level `README.md`) by the report's table generator; the column *report section* of the results → paper table in
the top-level `README.md` uses the same section numbers. Build: `pdflatex main && bibtex main && pdflatex main &&
pdflatex main` (TeX Live 2026).
The title page gives the arXiv numbers of the Letter (arXiv:2610.28704) and the paper (arXiv:2610.24905), the DOI of
this report version (10.5281/zenodo.23554537) and of all its versions (10.5281/zenodo.23434139), and the DOI of this
code and data record for all versions (10.5281/zenodo.23434067); this folder is a convenience copy of report version
1.1 inside the code and data record.
